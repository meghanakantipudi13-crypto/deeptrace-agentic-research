# Individual Process Log — Meghana Kantipudi

I used OpenAI Codex as an AI-assisted development partner for code drafting, debugging, refactoring, test design, and documentation review. DeepTrace itself uses Vertex AI Gemini 3.5 Flash-Lite as its optional production model provider; deterministic providers support repeatable local tests. I designed DeepTrace as an original agentic research application rather than an extension of the Assignment 3 personal assistant.

Development proceeded in controlled phases. I first built a typed LangGraph workflow for planning, query generation, retrieval, verification, criticism, query revision, and cited synthesis. I then added a real human approval interrupt, local cross-session research history, checkpoint persistence, retrieval-content quarantine, input validation, rate limiting, adversarial tests, and a quantitative evaluation harness. Codex generated or revised portions of the implementation and documentation under my direction. I reviewed the diffs, constrained each phase, ran the tests, inspected the user interface, and rejected claims that were not supported by evidence. I did not copy or substantially adapt another student's project or an external application; framework usage follows the installed libraries' documented APIs.

Verification included the complete automated suite, a 27-case deterministic evaluation, three real prompt-injection attacks against the workflow, restart-persistence tests, and one controlled live Vertex AI request through DeepTrace's production provider. I also checked compilation, dependencies, Git diffs, and tracked files for secrets. The main lesson was that agentic behavior is not just model prompting: typed state, explicit routing, checkpoints, trust boundaries, and measurable acceptance criteria are what make an agent reliable and auditable. I also learned to separate locally verified semantics from cloud capabilities that have only been implemented or remain future work.
